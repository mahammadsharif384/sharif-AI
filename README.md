# 🤖 Sharif AI

Sharif AI is an AI-powered student assistant built using HTML, CSS, and JavaScript. It helps users ask questions using text or voice input and displays AI-generated responses.

## 🚀 Features

- 🔍 Search questions
- 🎤 Voice input (Speech Recognition)
- 🤖 AI-generated responses
- 🌙 Dark UI
- 📱 Responsive design
- ⚡ Fast and simple interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Gemini API
- Web Speech API

## 📂 Project Structure

```
Sharif-AI/
│── index.html
│── style.css
│── scrept.js
│── dashboard.html
│── dashboard.css
│── dashboard.js
```

## ▶️ How to Run

1. Download the project.
2. Open it in VS Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Click **Open with Live Server**.
6. Ask a question and enjoy!
